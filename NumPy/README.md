# 🧩 NumPy Essentials & Operations

This folder contains all my practice tasks, concepts, and hands-on exercises for **NumPy** as part of my Data Science & Machine Learning journey.

---

## 📚 Concepts Covered

### 1. Fundamentals & Array Creation
- Special array initializations (`np.eye`, `np.zeros`, `np.ones`, etc.)
- Array Properties: Inspection of `shape`, `size`, `ndim`, and `dtype`

### 2. Indexing, Slicing & Reshaping
- Basic & Advanced Slicing, Boolean Indexing, Fancy Indexing
- Reshaping operations: `ravel()`, `flatten()`

### 3. Array Manipulation
- Structural changes: `insert()`, `delete()`, `concatenate()`
- Combining & Splitting: Stacking (`vstack`, `hstack`) and `split()`

### 4. Mathematical & Statistical Operations
- Descriptive Statistics: `mean()`, `median()`, and statistical aggregates
- Performance Optimization: **Vectorization** & **Broadcasting**

### 5. Data Cleaning & Inspection
- Handling missing data & special values: `isnan()`, `isinf()`, and Boolean filtering
